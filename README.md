# Bruma Roja

Landing page conceptual de cafe creada como pieza de portafolio.

## Descripcion

Bruma Roja es una propuesta premium y artesanal inspirada en una tostadora boutique. La landing busca transmitir origen, ritual, sabor y calidad percibida con una direccion visual calida y sensorial.

## Archivos

- `index.html`
- `styles.css`
- `script.js`

## Incluye

- hero con identidad de marca
- scroll suave entre secciones
- navegacion con seccion activa
- animaciones de entrada al hacer scroll
- microinteracciones sutiles
- diseno responsive

## Secciones principales

- lote de temporada
- origen
- ritual
- perfiles de sabor
- detalle de marca
- cierre premium

## Tecnologias

- HTML5
- CSS3
- JavaScript vanilla

## Publicacion en GitHub Pages

Sube estos archivos a un repositorio independiente:

- `index.html`
- `styles.css`
- `script.js`

Luego activa GitHub Pages desde la rama principal.

## Nota

Este proyecto fue creado como concepto visual de portafolio y puede adaptarse a una marca real de cafe, suscripcion o tostadora de especialidad.
